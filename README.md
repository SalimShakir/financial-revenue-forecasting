# Corporate Finance Analytics & Predictive Revenue Forecasting

## 📌 Business Challenge
I audited and restructured a raw, multi-currency corporate sales database to create a forward-looking financial performance model. The source accounting ledger was compromised by corrupted text columns, raw string symbols ($ , -), and uncalibrated data dimensions that skewed historical margins and blocked predictive timeline forecasting.

## 🛠️ Data Engineering & Sanitation (Spreadsheet Workflow)
I executed a comprehensive preprocessing matrix to prepare the data for business intelligence modeling:
* **Structural Error Resolution:** Repaired systematically corrupted text strings across organizational market sectors (e.g., standardizing truncated database string names).
* **Financial Data Type Transformation:** Stripped string symbols ($ , -) across Gross Sales, COGS, and Profit columns, converting text objects into active numeric integers to enable calculator operations.
* **Timeline Optimization:** Restructured text-based chronological fields into recognized chronological dates, aligning the historical ledger for time-series analysis.

## 📊 Business Intelligence & AI Predictive Modeling (Power BI)
I imported the clean financial core into Power BI Desktop to engineer an interactive executive interface:
* **Executive Performance Blocks:** Built a centralized KPI ledger tracking absolute baseline indicators: Gross Revenue ($118.73M), Net Profit ($18.45M), and Volume Throughput (1.13M Units Sold).
* **Market Sector Analysis:** Built a dynamic segment allocation wheel alongside country-level profitability rankings to isolate high-margin territories.
* **Time-Series Machine Learning Forecast:** Integrated Power BI's AI analytics engine to project a 12-month forward-looking revenue baseline utilizing exponential smoothing, bounded by a 95% statistical confidence interval.
